# Configurable warranty policies

The three top-level JSON files are unchanged source snapshots. POLICY_FIELD_MATRIX.csv checks every requested policy field. completion_templates contains all required keys, with blanks for missing start/repair/replacement conditions. The implementation team must choose these conditions and enforce them; added JSON keys alone do not implement rules. Do not replace runtime policies with unreviewed templates. Record policy approval in [[POLICY_APPROVER]].
