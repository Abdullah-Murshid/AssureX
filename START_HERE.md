## ⚡ How to Run in 10 Seconds

### Step 1: Launch Application
- **Windows:** Double click **`run_app.bat`** in this directory.
- **Terminal:** Open a terminal in `02 Source Repository` and run:
  ```bash
  python launch.py
  ```

### Step 2: Access Portal
Your browser will open automatically at:  
👉 **`http://127.0.0.1:8000`**
